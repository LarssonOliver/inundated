# inundated docs

Documentation site for [inundated](https://github.com/LarssonOliver/inundated), built with [Docusaurus](https://docusaurus.io/).

## Installation

```bash
npm install
```

## Local Development

```bash
npm run start
```

Starts a local dev server at http://localhost:3000/ with live reload.

## Build

```bash
npm run build
```

Generates a static site into the `build` directory.

## Typecheck

```bash
npm run typecheck
```

Runs the TypeScript compiler in check-only mode. There's no lint or test suite for this site yet — this is the only automated verification available.
