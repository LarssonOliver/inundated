# Calendar Access

inundated can show your time entries and tasks in other calendar apps over
CalDAV. Access is **read-only**: the apps display your data but can't change it.

- **Time** is a calendar of events, one per time entry.
- **Tasks** is a calendar of to-dos, one per task: open tasks, plus tasks
  closed in the last 30 days.

## Create a password

Open **Settings** and find the **Calendar access** card. Give the password a
name (for example the device it is for) and create it. The password is shown
once; copy it then. The list below the form shows when each password was
created and last used, and lets you revoke it. A revoked password stops
working at the next sync.

App passwords work only for calendar access, not for the rest of the API.

If you run inundated without login and later enable OIDC, every app password
created while the instance had no login is deleted when the first user signs
in. Create new ones afterwards.

The card also shows the server URL, `https://<your-host>/dav/me/`. The
**username can be anything**; it is ignored, and the password decides whose data
you see. After 10 failed attempts from one IP address within a minute, further
requests are answered with `429` for the rest of that minute.

:::note
Clients must reach inundated over **HTTPS**. macOS will not send the
credentials over plain HTTP, and account setup fails with "unable to verify
account name or password". See [Reverse Proxy](/docs/configuration/reverse-proxy).
:::

## Apple Calendar and Reminders

1. Open **Calendar → Settings → Accounts**, choose **+**, then **Other CalDAV
   Account**.
2. Set the account type to **Advanced** and fill in:
   - **User**: anything
   - **Password**: the app password
   - **Server**: your host name
   - **Server Path**: `/dav/me/`
   - **Port**: `443`
   - **Use SSL**: on
3. In **Internet Accounts**, make sure **Reminders** is enabled for the new
   account. Calendar only syncs the Time calendar and Reminders only syncs the
   Tasks calendar.

## DAVx⁵ (Android)

Add an account, choose **Login with URL and user name**, and enter
`https://<your-host>/dav/me/` as the base URL, any user name, and the app
password. Select the calendars to sync. Tasks need a task app that DAVx⁵
supports, such as tasks.org or OpenTasks.

## Limitations

- **Edits are reverted.** Apple's apps let you edit items, send the change,
  get it refused, and then silently restore the original on the next sync.
  Make changes in inundated.
- **Apple Reminders doesn't nest subtasks.** Every task appears at the top
  level. Clients that support RELATED-TO, such as Thunderbird or tasks.org,
  can show the hierarchy.
- **Ignored tasks are hidden in Apple Reminders.** They are sent as cancelled
  to-dos, which other clients may show.
- **Large histories make larger syncs.** The Time calendar includes your whole
  history, and Apple re-lists it on every sync (there's no incremental sync
  yet).
- **Closed tasks disappear after 30 days.**
- **Events use the time zone from Settings.** If it is set to follow the
  browser, events are sent in UTC, and Apple Calendar shows the GMT time
  alongside your local time.
